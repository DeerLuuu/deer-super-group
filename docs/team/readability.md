# 可读性字号（t184）

目标：整个桌面 UI 的字清晰、舒适，不再出现 9–10px 的实际正文。

## 字号层级

- 正文 / 对话 / Markdown：**14px**
- 控件（button / input / select / textarea）与 label：**12.5px**
- 代码 / pre / inline code：**12.5px**
- 思考原文与机翻正文：**13px**，行高 1.65
- 元信息（时间、状态、step、轨迹时间）：**12px**
- 面板标题：14–15px

## 覆盖范围

- 对话、思考、工具调用、轨迹；
- 设置 / 翻译 / Git 设置；
- 任务、团队、星图、邮箱、记忆、评审、提问卡片；
- 按钮、输入框、下拉框与标签。

## 说明

- 仅对真实文本设字号下限，图标 glyph（折叠箭头、状态点）保持原尺寸；
- 少量 `!important` 用于覆盖早期组件里 10–11px 的一次性字号；
- 不在本次改动调整布局宽度，只提高字号的视觉密度。
