## 0. 结论摘要（TL;DR）

1. **Obsidian 值得借鉴的不是「力导向」本身，而是「可探索的阅读层」**：hover 高亮邻居、local graph + 深度、过滤、分组着色、显示参数、点击打开、视口导航。
2. **任务图是语义化的有向无环依赖图（DAG），不是无向的笔记链接网**：层级位置本身携带「依赖先后」信息。默认布局必须保留分层 DAG；自由力导向只能作为可选的「探索模式」，不能做默认。
3. **当前星图已具备**：确定性分层布局、节点卡片（状态/负责人/依赖数）、有向依赖边、pan/zoom/fit、选中、C14 外部 focus、成员过滤（TeamDashboard 外部）、空状态。**缺失**：hover 邻居高亮、节点拖拽、状态/搜索/孤立过滤、分组着色与图例、显示设置（标签衰减/节点大小/连线粗细/箭头开关）、local focus 深度、minimap、键盘可达、右键菜单、视图状态持久化、画布/规模策略。
4. **推荐模型**：DAG 默认 + Obsidian 式探索层。P0 做 hover 邻居高亮、过滤条、显示设置、local focus（1–3 跳）、点击/键盘/右键基础；P1 做分组/图例、minimap（>30 节点）、搜索飞行、视图保存；P2 才考虑可选力导向探索模式、节点临时拖拽、画布渲染。
5. **不照搬**：力导向默认布局、Obsidian 的搜索查询分组语言、tags/attachments/unresolved 等笔记语义、按引用数决定节点大小作为唯一编码、动画按创建时间回放（对本产品收益低）。
6. **最大风险**：过滤把依赖藏掉造成误读、力导向破坏 DAG 可读性、节点拖拽后位置与真实层级不一致、DOM 卡片在节点数增长后掉帧、hover-only 交互对键盘/触屏不可达。

## 1. Obsidian Graph View 功能清单

> 说明：以下是 Obsidian 原生 Graph view 的能力；标注「插件/非原生」的项不要当作官方默认能力。

| 类别 | 功能 | 行为 / 细节 | 对任务星图的参考 |
|------|------|-------------|------------------|
| 视图范围 | Global graph | 整个 vault 的链接网络，受过滤/排除规则影响 | 对应「全部任务」 |
| 视图范围 | Local graph | 以当前笔记为中心，只显示其连接邻域 | 对应「聚焦某任务的上/下游子图」 |
| 视图范围 | Local depth | local graph 的深度滑杆，逐层展开邻居（1 层起，逐级加深） | 对应依赖深度 1–3 跳（上游/下游/双向） |
| 节点 | 笔记节点 | 圆形；节点文字为笔记名 | 任务是卡片，不是圆点；需要「卡片/紧凑/圆点」密度模式 |
| 节点 | 标签 / 附件 / 未解析链接 | 可分别开关；未解析链接也是节点 | 任务没有这些语义；可替换为「未分配/孤立/被阻塞」等任务状态节点 |
| 节点 | 节点大小 | 被引用越多，圆越大（官方行为） | 任务可按「被依赖数/依赖数」放大，但只能作为辅助编码，不能替代状态色 |
| 节点 | 颜色 | 主题默认色 + CSS 变量；分组可覆盖 | 任务已有状态色 token；可增加负责人分组色/图例，但要避免双重编码冲突 |
| 连线 | 内部链接 | wikilink / Markdown link；无类型、无权重 | 任务是「依赖」有向边；方向与类型比 Obsidian 更重要 |
| 连线 | 箭头 | Display 中可开关箭头 | 当前已有箭头；应保留且可开关（探索时关闭可降噪） |
| 连线 | 连线粗细 | Display 中可调 | 可用「关键路径/阻塞边」加权，而不仅是视觉粗细 |
| 导航 | 缩放 | 鼠标滚轮、`+`/`-` 键 | 当前已有滚轮与按钮；补键盘 `+`/`-`/`0` |
| 导航 | 平移 | 拖拽背景、方向键（Shift 加速） | 当前拖拽已有；补方向键与 Shift 加速 |
| 探索 | Hover 高亮邻居 | 悬停节点时高亮其连接，弱化其余 | **最值得借鉴的交互**；任务图可区分上游/下游 |
| 探索 | 点击打开 | 点击节点打开笔记；右键有动作菜单 | 当前单击选中、双击打开；建议保留单击选中，双击/回车打开，补右键菜单 |
| 过滤 | Search files | 搜索语法过滤（`path:`、`tag:`、`[property:value]` 等） | 任务可用标题/ID/负责人/状态/依赖数简单过滤；不需要完整查询语言 |
| 过滤 | Tags / Attachments | 显示或隐藏标签/附件节点 | 无对应数据；不要为对齐而新增标签字段 |
| 过滤 | Existing files only | 隐藏未创建的链接目标 | 对应「隐藏无对应任务/已删除依赖」；当前 DAG 已按存在任务构图 |
| 过滤 | Orphans | 显示/隐藏无链接节点（注意不是「只看孤立」） | 对应「孤立任务/无依赖任务」高亮或过滤，需明确语义 |
| 分组 | Groups | 每条分组 = 搜索查询 + 颜色；保存在 vault（`.obsidian/graph.json`） | 任务可用「状态/负责人/优先级」做固定分组，不需要查询语言 |
| 显示 | Arrows | 箭头开关 | 建议保留开关 |
| 显示 | Text fade threshold | 缩放时文字淡出阈值 | **高价值**：低缩放隐藏标签、放大显示，解决卡片文字在 30% 时不可读 |
| 显示 | Node size | 节点大小滑杆 | 建议改为「密度模式（卡片/紧凑/圆点）+ 节点尺寸」组合 |
| 显示 | Link thickness | 连线粗细 | 建议保留，用于区分关键路径或减弱背景边 |
| 显示 | Animate | 按创建时间回放节点出现 | 对任务地图收益低、易误导，建议不做或放 P2 |
| 力参数 | Center force | 控制整体紧凑/圆形程度 | 仅自由布局需要；DAG 默认不使用 |
| 力参数 | Repel force | 节点间斥力 | 同上；若做探索模式再开放 |
| 力参数 | Link force | 连线拉力 | 同上 |
| 力参数 | Link distance | 连线长度 | 同上 |
| 布局操作 | 手动拖节点 | 原生可拖动单个节点；**位置不会保存**，论坛长期有「保存节点位置」需求 | 任务图可做「临时拖拽 + 一键复位」，但不建议持久化位置（会与层级语义冲突） |
| 布局操作 | Pin / 多选拖拽 / 保存布局 | **非原生**，由社区插件补足（如 GraphFrontier） | 不要假设官方默认能力；若要做，需自研并明确成本 |
| 导航辅助 | Minimap | **本次调研未发现官方内置 minimap**；社区/第三方工具有类似能力 | 若要，需自绘（视口矩形 + 点击/拖拽平移）；<30 节点不建议做 |
| 渲染 | Canvas 渲染 | Graph view 用 canvas 绘制，非 DOM 元素；CSS 只能改颜色变量，不能改形状/布局 | 当前任务图是 DOM 卡片 + SVG 边；<100 节点可继续 DOM，规模上去再评估 canvas |
| 其他 | 恢复默认设置 | 设置面板右上角可恢复默认 | 建议显示设置也提供「恢复默认」 |
| 其他 | 视图书签 | 可保存不同过滤条件下的 graph view（论坛提及） | 对应「保存视图（过滤+显示+焦点）」，P1 可做 |

**官方能力边界提醒**：minimap、pinning、多节点拖拽、布局保存不是 Obsidian 原生 Graph view 的必备项；本次调研把「原生」与「插件补齐」分开，避免把插件能力当成默认参考。

## 2. 可借鉴 / 不适用

### 2.1 可借鉴（按对本项目的价值排序）

1. **Hover 邻居高亮**：悬停节点 → 高亮直接上游/下游与相关边，其余降到 20–30% 不透明度。对任务图能立刻回答「这个任务卡在谁身上/会影响谁」。
2. **Local graph + depth**：以当前任务为中心，1–3 跳上下游子图；对应「聚焦当前任务」。这是把 Obsidian 的 local graph 语义迁移到 DAG 的最自然方式。
3. **过滤条**：状态 chips、负责人、搜索、孤立/无依赖、仅阻塞；对任务数增长后的日常使用必要。
4. **显示设置**：文字衰减阈值、节点密度（卡片/紧凑/圆点）、连线粗细、箭头开关。解决缩放后文字不可读、卡片太占空间。
5. **分组/图例**：状态色已有；可加负责人色/分组图例，但只允许一个主编码，避免状态色与负责人色互相打架。
6. **点击/右键**：单击选中、双击打开、右键菜单（打开会话、定位、复制 ID、查看依赖）；当前缺右键。
7. **键盘导航**：方向键平移、`+`/`-`/`0` 缩放/适应、Enter 打开、Esc 清除；C27 未采纳，但本轮可单独提案。
8. **视图状态持久化**：过滤/显示/焦点按工作区记忆；刷新后恢复，和 C12 深链不冲突。
9. **Minimap（有条件）**：节点 >30 或缩放后仍需要全局定位时再加；小图不做。
10. **Canvas/WebGL（后置）**：节点规模到 100–200+ 且 DOM 掉帧时再评估；当前不预支复杂度。

### 2.2 不适用 / 不建议照搬

1. **力导向作为默认布局**：任务图的 x 轴 = 依赖层级，y 轴 = 同层排序；力导向会让「谁依赖谁」的位置语义消失，产生错误聚类暗示。
2. **按引用数放大节点作为唯一编码**：Obsidian 是知识网络，任务是执行图；节点大小应优先表达状态/阻塞，而非「被引用多」。
3. **Obsidian 搜索查询语言**：`path:`/`tag:`/`[property:value]` 对任务数据过重；简单关键字 + 状态/负责人即可。
4. **Tags / Attachments / Unresolved 过滤**：当前 Task 没有这些字段；不要为「像 Obsidian」而新增数据模型。
5. **Animate（按创建时间回放）**：任务图关心当前依赖与阻塞，不关心「何时创建」的时间-lapse；易误导。
6. **保存节点位置 / pin**：原生 Obsidian 也不保存位置；任务图如果持久化手动位置，会让「层级=依赖」失真，还会在任务新增后过期。最多做临时拖拽 + 复位。
7. **Minimap 默认常驻**：小图上是纯装饰；按节点数阈值出现。
8. **把 Obsidian 的全局图直接等同「全部任务」**：任务图需要方向、状态、负责人、阻塞；只抄视觉会得到一张「好看但不能执行」的图。

## 4. 任务 DAG 与自由力导向图的差异

| 维度 | 任务 DAG（当前） | Obsidian 自由图 | 设计含义 |
|------|------------------|-----------------|----------|
| 关系语义 | `dependsOn`：有向、先决条件、无环 | 内部链接：有向可关箭头、可成环、无类型 | 位置和箭头是语义，不是装饰 |
| 布局 | 分层：x = 依赖深度，y = 同层顺序；确定性 | 力导向：位置由斥力/拉力/初始随机决定 | 不能用自由力导向做默认，否则「谁先谁后」丢失 |
| 位置含义 | x 轴表达依赖层级 | 位置不表达语义，只表达聚类 | 拖拽/保存位置会破坏语义 |
| 节点信息 | 卡片：状态/负责人/依赖数/标题 | 圆点：标题；大小=引用数 | 任务需要信息密度；Obsidian 的圆点只能做低缩放概览 |
| 规模 | 几十个任务 | 数百到数千笔记 | DOM 卡片当前够用；不要预支 canvas 复杂度 |
| 数据变化 | 任务状态/依赖会变，图需重排/局部更新 | 笔记链接相对静态 | 布局稳定性和增量更新更重要；力导向会抖动 |
| 过滤风险 | 过滤掉上游会让下游看起来「无依赖」 | 过滤只是减少节点，不改变语义 | 过滤必须保留「隐藏了 N 个依赖」的提示，或只 dim 不 hide |
| 目标 | 执行监控：卡在哪、谁负责、下一步 | 知识探索：发现连接、孤立笔记 | 借鉴探索交互，不照搬知识网络隐喻 |

**核心判断**：Obsidian 的「自由」来自无固定语义的位置；任务图的「可信」来自固定语义的位置。两者可以共存，但必须**模式分离**：默认 DAG，探索模式可选、可退出、有明确标识。

## 5. 推荐交互模型（保留 / 新增 / 风险）

### 5.1 保留（不要重做）

| 保留项 | 理由 |
|--------|------|
| 分层 DAG 默认布局 | 依赖先后是任务图的第一信息；确定性布局可跨刷新稳定对比 |
| 节点卡片（详细模式） | 状态、负责人、依赖数、标题是执行监控的最小信息集 |
| 有向边 + 箭头 + done 变色 | 方向与完成态是核心语义 |
| pan / zoom / fit | 已有交互成熟，回归风险低；保留快捷键与双击复位 |
| App 级选中 + C14 focus | 任务页/团队页/对话页共享当前任务；定位已修复，不重新发明 |
| 成员过滤 | 已有入口在团队页左侧；星图内部过滤条应复用同一状态，而不是替换 |
| 空状态 C24 | 统一空态组件已存在，保持 |
| 状态色 token | C01 已统一；新视觉必须复用 `--status-*`，不要新增色板 |

### 5.2 新增（建议按 P0/P1/P2 分批）

| 优先级 | 新增能力 | 说明 / 验收要点 | 成本 |
|--------|----------|------------------|------|
| **P0** | Hover 1 跳邻居高亮 | 悬停节点：高亮直接上游/下游节点与相关边，其余降透明；tooltip 显示「上游 N / 下游 N / 负责人 / 状态」；移出恢复 | M |
| **P0** | 过滤条 | 状态 chips + 负责人 + 关键字 +「孤立/无依赖」+「仅阻塞」；计数；清除全部；过滤结果与成员过滤叠加 | M |
| **P0** | 显示设置 popover | 标签衰减阈值、节点密度（卡片/紧凑/圆点）、连线粗细、箭头开关；恢复默认；按工作区持久化 | M |
| **P0** | Local focus（1–3 跳） | 聚焦选中任务；上游/下游/双向；深度 1–3；面包屑「全部任务 › 聚焦：xxx」；Esc/按钮退出；节点数统计 | M |
| **P0** | 点击/右键/键盘基础 | 单击选中、双击/Enter 打开；右键菜单（打开会话、复制 ID、定位、查看依赖）；方向键平移、±/0 缩放适应、Esc 清除；节点 `tabIndex`/`aria-label`/focus-visible | M |
| **P1** | 分组着色 + 图例 | 状态（默认）/负责人两种分组；图例可折叠；不与状态色冲突（负责人用描边/环，不用填充） | S/M |
| **P1** | Minimap（条件） | 仅节点 >30 显示；视口矩形、点击/拖拽平移、可折叠；不抢主画布 | M |
| **P1** | 搜索 + fly-to | 关键字匹配标题/ID/负责人；结果列表；选中后平移居中并高亮；无结果提示 | S/M |
| **P1** | 视图保存/恢复 | 过滤 + 显示 + focus 存 localStorage（按 workspace）；「重置视图」；不持久化节点坐标 | S |
| **P2** | 可选「探索模式」 | 力导向布局，仅作为可切换模式；顶部明确标识「探索模式 · 位置不代表依赖」；一键回 DAG；不默认 | L |
| **P2** | 节点临时拖拽 | 拖拽 = 临时偏移（可复位），不写回；拖动时显示虚线或「已移动」标记；换布局/刷新复位 | M |
| **P2** | 语义缩放/圆点概览 | 低缩放自动切圆点/只留状态点；高缩放回卡片；阈值可配 | M |
| **P2** | canvas/性能策略 | 节点 >100 时评估 canvas 分层渲染/虚拟化；给出交互帧率预算 | L |

### 5.3 明确不借鉴 / 缓做

- 力导向默认布局、把 center/repel/link 参数作为主设置；
- Obsidian 查询语言式 Groups、tags/attachments/unresolved 过滤；
- 按引用数放大节点作为唯一视觉编码；
- 按创建时间回放动画；
- 保存/固定节点位置作为默认（临时拖拽可以，持久化不建议）；
- 小图常驻 minimap；
- 为「像 Obsidian」新增任务字段/后端数据。

### 5.4 关键交互规格建议

1. **节点状态**：default / hover / selected / neighbor / dimmed / filtered；selected 与 hover 叠加时选中优先；dimmed 透明度 0.25–0.3。
2. **边状态**：default / connected-hover / done / critical（关键路径）；hover 时相关边 2px、其余 0.15 透明度；箭头保留。
3. **Hover 延迟**：120–180ms 防抖，避免扫过时闪烁；tooltip 跟随节点，不遮标题。
4. **Local focus**：默认 1 跳；深度 2–3 时显示「第 N 层」浅色环；上游/下游不同边色（如上游蓝、下游紫），但需与状态色区分；退出恢复 fit。
5. **过滤**：优先「dim 不 hide」用于探索；「只看」模式才 hide，并在标题栏显示「已隐藏 N 个任务（含 M 条依赖）」，避免误读；过滤与成员过滤共用状态。
6. **显示设置**：标签衰减阈值 0.5–1.2；节点密度三档；连线粗细 1–3px；箭头开关；全部即时预览 + 恢复默认。
7. **Minimap**：140×96，左下角；半透明；视口矩形；点击/拖拽平移；仅 >30 节点；可关闭并记忆。
8. **键盘**：方向键平移、Shift 加速、`+`/`-` 缩放、`0` 适应、Enter 打开、Esc 清除/退出 focus；焦点环 2px；所有交互有等价鼠标路径。
9. **持久化**：`starmap.view`（过滤/显示/focus/折叠状态）按 workspace；版本号 + 容错；「重置视图」；不存坐标。
10. **空/小图**：0 任务用 EmptyState；1–3 任务不显示 minimap/分组，保持简洁。

### 5.5 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 力导向/拖拽破坏 DAG 语义 | 用户误读依赖先后 | DAG 默认；探索模式明确标识；拖拽临时且可复位 |
| 过滤隐藏依赖 | 下游看起来「无依赖」，误判可运行 | 优先 dim；hide 时显示隐藏计数与「依赖被隐藏」警告 |
| 视觉编码过载 | 状态/负责人/分组/节点大小互相打架 | 单一主编码（状态色）；负责人用描边；图例可折叠 |
| Hover-only 交互不可达 | 键盘/触屏用户无法获取邻居信息 | hover 信息同时进 tooltip/详情面板；键盘 focus 触发同样高亮 |
| DOM 卡片规模 | 节点多时拖拽/缩放掉帧 | 先测 50/100/200 节点；超过阈值走 canvas/概览模式；P2 再做 |
| Minimap 抢空间 | 小图纯装饰、遮挡内容 | 仅 >30 节点；可折叠；不与详情面板重叠 |
| 视图状态过期 | 过滤后看不到新任务，误以为丢失 | 顶部常驻「过滤中」提示 + 清除；新任务计数 |
| 模仿插件能力 | minimap/pin/多选拖拽被误认为原生低成本 | 研究文档标注「非原生」；提案需写自研成本与验收 |
| 减少动效/无障碍 | 脉冲/过渡引发不适；节点不可聚焦 | 尊重 `prefers-reduced-motion`；节点可聚焦、aria-label、键盘路径（C27 可并入本轮） |
| 范围膨胀 | 一轮做成完整图谱产品 | P0/P1/P2 分层；提案必须标成本与依赖；先交 P0 |

## 7. 结论

任务星图不应该变成「Obsidian 的截图复刻」。正确的目标是把 Obsidian 的**探索手感**（hover 邻居、local depth、过滤、分组、显示参数、视口导航）叠加到**可信的 DAG 执行图**上：默认仍是分层依赖图，探索层可开可关；过滤优先 dim、少 hide；节点位置不持久化；力导向只作为明确的探索模式。这样既保留任务图的可信度，又补上「看全局—聚焦—找邻居—过滤—定位」的探索链路。
