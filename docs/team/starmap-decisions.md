## 实现阶段 Obsidian 参考取舍建议（供 t46 / t47 / t48）

### 1. 力导向 vs 分层（S01 + S02）

- **默认采用 S02 的确定性力导向/混合布局**：以依赖深度分层坐标作**初始种子**，叠加 seeded force（center/repel/link distance + 依赖 x 软约束），固定迭代/α 衰减、收敛即停；同输入快照坐标逐坐标一致。
- **不要回到 210×86 卡片/纯分层展示**：节点是 6–14px 圆点/圆环；分层只作为「种子 + 方向约束」，不是视觉形态。
- 力参数**只暴露少量预设**（紧凑/标准/舒展）或内部固定，不把 center/repel/link 全部交给用户；提供「复位布局」。
- 依赖方向靠箭头/边语义与 x 软约束保留；不得用自由漂移掩盖方向。
- C14 focus 后**不自动重排**；任务更新不 auto-fit（见 S12）。

### 2. 局部图 / Local Focus（S06）

- 借鉴 Obsidian local graph + depth：聚焦任务 1–3 跳，支持上游/下游/双向；默认 **dim 范围外**，不删除、不重排。
- 只有显式「隐藏范围外」才 hide，并显示「隐藏 N 任务 / M 依赖边」；面包屑「全部任务 › 聚焦：任务名 · 双向 2 跳 · 8/24」，Esc/按钮退出并恢复进入前视口。
- C14「在星图中定位」在聚焦态必须可用；不要因聚焦重建整图。

### 3. 过滤（S07）

- 借鉴 Obsidian Filters 的「可见条件 + 计数 + 清除」，但**不用查询语言**。
- 默认 **dim**：不匹配节点 0.15/0.25，布局不重算；「只看」才 hide，必须常驻「已隐藏 N 任务 / M 依赖边 / K 跨边界」并给被隐藏依赖加虚线/角标。
- 成员过滤必须提升为受控状态（不能先裁任务再构图）；空结果区分「真无任务」与「当前过滤下没有任务」。
- 状态色复用 C01 token，不造第二套映射。

### 4. 标签（S03）

- 借鉴 Obsidian Text fade threshold：三档 LOD（<0.55 点；0.55–0.9 单行标题；≥0.9 完整标签），**节点本体保持圆点/圆环**，不恢复卡片墙。
- selected/hover 任意缩放强制全标签；同屏标签 ≤24，取舍顺序 selected > hover > failed/blocked > 其他；截断保留 title 全量。
- 阈值常量化，便于 QA 复现；标签避让可先用简单错位/碰撞，不阻塞主功能。

### 5. 可达性（S11 + S05）

- 节点改 `<button>`，Tab 顺序按依赖层级；Enter=选中并开浮窗，Ctrl/⌘+Enter=打开会话；`aria-label` 含标题/状态/负责人/N 依赖。
- 画布可聚焦：方向键平移（Shift 加速）、`+`/`−`/`0`、Esc 关浮窗/退聚焦；`:focus-visible` 2px 环。
- 浮窗 `role="dialog"` + `aria-modal="false"`，焦点入首个动作、Tab 循环、Esc 回焦触发节点；dim 节点仍可聚焦并恢复全亮。
- `prefers-reduced-motion` 下 fit/focus/脉冲/渐变改瞬时；hover-only 不可作为唯一路径（S05 的键盘 focus 等价是硬要求）。
- 浮窗与双击判定 ≤250ms；右键/「…」菜单与双击走同一 `onOpen`（C14 链路）。

### 6. 明确不借鉴 / 本轮不做

- 不做 Obsidian 的查询语言式 Groups、tags/attachments/unresolved 过滤（无字段，不造节点）。
- 不做按引用数放大节点作为唯一编码；节点尺寸只作辅助（度数/状态权重），状态必须颜色+形状双编码。
- 不做按创建时间回放动画；不做保存节点坐标/pin（临时拖拽 S13 未采纳，首访提示中隐藏该行）。
- minimap、pin、多选拖拽、布局保存属插件/自研能力，本轮不做；S14 性能分级未采纳，但保留基本性能自测。
- S09 分组切换未采纳：S08/S10 的图例只列「状态色 + 依赖实线/归属虚线 + 尺寸含义」，不展示负责人/深度分组。

### 7. 已知风险（t46/t47 重点）

| 风险 | 缓解 |
|------|------|
| 力导向布局漂移/刷新跳变 | seeded PRNG、固定迭代、坐标缓存；只在显式复位/新任务提示时重排 |
| 过滤隐藏依赖导致误读 | dim 优先；hide 显式 + 隐藏计数 + 被隐藏依赖虚线/角标 |
| 单击/双击冲突 | ≤250ms 判定；双击不叠加浮窗；空白/Esc 关闭 |
| 标签重叠/低缩放不可读 | LOD 阈值 + 同屏 ≤24 + selected/hover 全标签 |
| 浮窗焦点丢失 | 焦点入/循环/回焦 + Esc；与 C25 Modal 工具复用 |
| 100 节点性能 | 即使 S14 未采纳，也需基本 culling/memo 自测；不阻塞 pan/zoom |
| 图例缺失导致 owner/状态误读 | S08 固定图例：依赖实线箭头 vs 归属虚线无箭头；S10 首访图例 |

## 验证口径建议（t47）

1. **8 节点 DAG 夹具**：链 1→2→3、扇出 2→{4,5,6}、汇聚 {4,5}→7、孤立 8；断言节点数=8、依赖边数=7、无伪造边。
2. **确定性**：同一快照两次挂载坐标逐节点相等。
3. **视觉**：默认截图中无 210×86 卡片；节点为圆点/圆环；边 1px；深色底。
4. **交互**：单击浮窗字段/动作；双击落到 `#/chat?task=` 且 C14 返回团队；Esc/空白关闭。
5. **局部图**：1–3 跳节点数正确；隐藏依赖计数正确；退出恢复视口。
6. **过滤**：dim 时节点/边数不变；hide 计数正确；成员过滤后不再误报「还没有任务」。
7. **标签**：0.3/0.6/1.0 三档内容符合 LOD；selected 在低缩放仍全标签。
8. **键盘**：Tab→节点→Enter→浮窗→Tab 循环→Esc 回焦；Ctrl+Enter 开会话。
9. **性能**：100 节点 pan/zoom 基本流畅（S14 未采纳，作为观察项不是阻断项）。
